# Docs

- `docs/hypotheses/` holds what is proposed, each file opening with a Status line. `docs/` holds what is built.
- State what the thing does and why, in the present tense. No praise, no history ("added", "now", "used to"), no restating the request.
- A convention that changes changes `docs/development.md` in the same commit.
